# PROJECT DESCRIPTION
The Cloud-Based Waste Collection and Recycling Management System is an AWS-based application designed to improve and simplify municipal waste management operations. It provides a centralized platform for administrators to register waste collection points, schedule pickups, assign vehicles and drivers, track collection status, and monitor recycling statistics.

The project uses AWS services such as Amazon EC2, Amazon ECR, Amazon RDS, Elastic Load Balancer, EC2 Auto Scaling, Amazon VPC, and CloudWatch. Docker containers are deployed on EC2 instances to ensure scalability and availability, while Amazon RDS stores operational records securely. CloudWatch monitors application performance, resource utilization, and errors.
